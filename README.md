# Rock Paper Scissors

This is a web-based implementation of the classic game Rock Paper Scissors, created as part of [The Odin Project's Foundations Course](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

## Description

The player competes against a computer opponent that makes random selections. The game features a graphical user interface styled with CSS, allowing users to play by clicking buttons.

## How to Play

1. Open `index.html` in your browser.
2. Click the **Rock**, **Paper**, or **Scissors** buttons to play a round.
3. The results will be displayed on the screen.

## Technologies Used

- HTML
- JavaScript
- CSS
